## Architecture Summary

Space Invaders Deluxe is a single-process pygame game with a scene-graph managed by a
`next_scene` pointer pattern in a 60 Hz main loop. Two modes share all gameplay logic:
**Arcade** (224×256 native, 3× nearest-neighbor, CRT overlay) and **Avatar** (448×512
native, 2× smooth, procedural Memoji faces). `ModeConfig` is the single source of truth
for all pixel positions and speeds; entities are constructed with it and must not read
from `constants.py` for coordinate values. Assets are loaded once at startup via
`AssetManager`. External avatar PNGs override procedural generation via
`AvatarGenerator._try_load_external()`. Trust boundaries are local-only — no network,
no subprocess, no user-controlled file paths at runtime. Main risk areas: (1) completeness
of `ModeConfig` adoption across all entities, (2) test suite contamination by real asset
files checked into the repo, (3) sprite display sizes not scaling with `coord_scale`.

## Patch Suggestions

### R010 — Fix cutscene.py linter violation

```python
# src/space_invaders/scenes/cutscene.py:108–111 — BEFORE
            sprite = pygame.transform.scale(
                sprite,
                (sprite.get_width() * sprite_scale, sprite.get_height() * sprite_scale),
            )

# AFTER
            sprite = pygame.transform.scale(
                sprite,
                (
                    sprite.get_width() * sprite_scale,
                    sprite.get_height() * sprite_scale,
                ),
            )
```

### R002 — Player sprite scaling

```python
# src/space_invaders/entities/player.py — BEFORE (lines 24–29)
        frames = asset_mgr.get_sprite_frames("player")
        self._sprite = frames[0]
        w = self._sprite.get_width()
        h = self._sprite.get_height()

# AFTER
        frames = asset_mgr.get_sprite_frames("player")
        raw = frames[0]
        cs = self._cfg.coord_scale
        self._sprite = (
            pygame.transform.scale(raw, (raw.get_width() * cs, raw.get_height() * cs))
            if cs != 1 else raw
        )
        w = self._sprite.get_width()
        h = self._sprite.get_height()
```

Apply the same pattern to UFO (`ufo.py:29–33`) and SplitAlien (`split_alien.py:76–79`).

### R001 — Fix test fixture contamination

```python
# tests/test_avatar_config.py — BEFORE (fixture uses AvatarConfig() directly)
@pytest.fixture
def config():
    return AvatarConfig()

# AFTER — force default characters regardless of real config.json
@pytest.fixture

    monkeypatch.setattr(AvatarConfig, "CONFIG_PATH", tmp_path / "nonexistent.json")
    return AvatarConfig()
```

### R006 — HUD font size

```python
# src/space_invaders/hud.py — BEFORE
class HUD:
    def __init__(self):
        self._font = pygame.font.Font(None, 8)

# AFTER
class HUD:
    def __init__(self, coord_scale: int = 1):
        self._font = pygame.font.Font(None, 8 * coord_scale)
```

Update `GameScene.__init__` to pass `self.mode_config.coord_scale`:
```python
self.hud = HUD(self.mode_config.coord_scale)
```
