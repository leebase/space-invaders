# Code Review — 2026-03-07

## Architecture Summary

Space Invaders Deluxe is a pygame-ce based recreation of the 1980 Taito arcade classic. It renders at 224×256 native resolution scaled 3× with a CRT scanline overlay. The architecture uses a Scene pattern (Title → Game → Cutscene → GameOver) with entity-based game objects (Player, InvaderGrid, UFO, Bunkers, SplitAlien, etc.). State management is explicit via enum-based state machines in GameScene and UFO/SplitAlien. Assets are procedurally generated as fallbacks if disk files are unavailable. Sound uses a 4-note march sequencer locked to visual march tempo. All 203 tests pass and ruff linting is clean.

**Entrypoint:** `space-invaders` CLI command → `main.py:main()`  
**External dependencies:** pygame-ce, numpy (pixel ops), requests/Pillow (asset download, unused in current build)  
**Trust boundaries:** No user input reaches subprocess/file paths; all input is keyboard-only via pygame events.

### R002: Robust ASSETS_DIR Resolution

```python
# src/space_invaders/assets.py:204 — BEFORE
ASSETS_DIR = Path(__file__).parent.parent.parent.parent / "assets"

# AFTER — Option 1: Use resolve() for clarity
ASSETS_DIR = Path(__file__).resolve().parents[3] / "assets"

# AFTER — Option 2: Find project root marker
_ROOT_MARKER = ".git"  # or "pyproject.toml"
def _find_project_root() -> Path:
    p = Path(__file__).resolve()
    for parent in p.parents:
        if (parent / _ROOT_MARKER).exists():
            return parent
    return p.parents[3]  # fallback
ASSETS_DIR = _find_project_root() / "assets"
```
