# Code Review — 2026-03-07 (Sprints 1–3)

## Architecture Summary

Space Invaders Deluxe is a single-process pygame-ce game targeting 224×256 native resolution scaled 3× to 672×768. The entry point (`main.py`) inits pygame, calls `ensure_assets()` to populate an `AssetManager` (disk-load or procedural fallback for every sprite and sound), then runs a 60fps game loop that delegates to a `Scene` hierarchy. Currently only `GameScene` is active; it owns an `InvaderGrid` (march + animation), a `Player` stub, a `UFO` stub, a `BunkerGroup` stub, and a `HUD`. The `Renderer` owns the 224×256 `pygame.Surface` that all drawing targets, and blits a nearest-neighbor scaled copy to the window each frame. External dependencies are limited to asset files under `assets/` (gitignored, not yet downloaded). No user input is trusted with file paths or subprocess calls. Security surface is minimal.

## Remediation Roadmap

### Fix Now (Blockers)
- **R001** — No tests means regressions are invisible from this point forward. Every subsequent sprint touches code that depends on march mechanics and asset loading. Even 3 focused tests would catch the most likely breakages.
- **R004 (HUD score)** — Score ≥ 10,000 (common in a normal game) will display wrong. Needs fixing before Sprint 4 where scoring goes live.

### Fix Soon (High ROI)
- **R002** — March boundary off by 2–4px. Harmless visually at full grid, but will produce clearly wrong wall-bounce positions once the grid thins out in later rounds. Fix before Sprint 4 makes it observable. (S effort)
- **R003** — `while` vs `if` in `update()`. Rare in practice but the right thing; one-line fix. (S effort)
- **R007** — Max-width boundary: same fix cycle as R002. (S effort)

### Fix Later (Refactors)
- **R005** (`ASSETS_DIR`) — Only matters for non-editable installs, which aren't a near-term concern. Document the limitation in `CLAUDE.md` for now.
- **R006** — Spritesheet validation: add when real sprites are dropped in (Sprint 2 follow-up).
- **R008** — Ruff config: one-line pyproject.toml change, do any time.
- **R009** — Line length: auto-fix + manual; low cognitive cost, do with R008.
- **R010** — Docstring: cosmetic, fix in passing.

## Patch Suggestions

**R003 — `while` loop in `InvaderGrid.update()` (`grid.py:60`)**
```python
# BEFORE
if self.march_timer_ms >= interval:
    self.march_timer_ms -= interval
    self._march_step()

# AFTER
while self.march_timer_ms >= interval:
    self.march_timer_ms -= interval
    self._march_step()
    interval = march_interval_ms(self.total_alive)  # recompute after each kill
```

**R004 — HUD score format (`hud.py:31`)**
```python
# BEFORE
rendered = self._font.render(f"{v:04d}", False, constants.COLOR_WHITE)

# AFTER
rendered = self._font.render(f"{min(v, constants.HIGH_SCORE_MAX):05d}", False, constants.COLOR_WHITE)
```

**R008 — ruff config (`pyproject.toml`)**
```toml
# BEFORE
[tool.ruff]
line-length = 88
select = ["E", "F", "W", "I"]
ignore = []

# AFTER
[tool.ruff]
line-length = 88

[tool.ruff.lint]
select = ["E", "F", "W", "I"]
ignore = []
```

**R002 — Boundary centering (`grid.py:138-139`)**
```python
# BEFORE
left_edge  = self.grid_x + left_col  * constants.CELL_W
right_edge = self.grid_x + right_col * constants.CELL_W + sprite_w_right

# AFTER (accounts for centering of sprite within cell)
sprite_w_left = self._frames[constants.ROW_TYPES[self._topmost_alive_row_in_col(left_col)]][0].get_width()
left_edge  = self.grid_x + left_col  * constants.CELL_W + (constants.CELL_W - sprite_w_left)  // 2
right_edge = self.grid_x + right_col * constants.CELL_W + (constants.CELL_W + sprite_w_right) // 2
```
